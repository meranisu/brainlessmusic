## what changed

small fixes for the song menu and data saver from the last update:

- "play next" when nothing is playing now says it's playing the song, because that's what it does
- song details showed dates in UTC, so a song played early in the morning could show as the day before. fixed
- if you opened details for two songs quickly, you could get the first one's info. fixed
- the drag handle in the queue is easier to grab now
- with data saver on, the app no longer sets up the player at launch before you've played anything

## upgrading

install over whatever version you have, you stay logged in. no server update needed
