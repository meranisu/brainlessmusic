## what changed

- sharing a listen together room now sends a link instead of just the code. if your friend has the app, tapping it opens the app with the code already filled in, and one tap on join gets them in
- no app? the same link opens the website, where they can sign in and land in the room, or grab the apk from there
- if you tap a room link while you're already in a different room, it asks whether to switch instead of yanking you out

## upgrading

the update sheet will offer it. links only start opening in the app once you're on this version, before that they open in the browser
