## what changed

downloads got a search box:

- type an album, playlist, artist or song name and it narrows down as you go. caps and accents don't matter, so "beyonce" still finds Beyoncé
- on All it shows matching songs too, under the albums and playlists, so searching a song title actually finds it
- the chips still work while searching, so Albums + "road" only shows albums
- new sort button next to the search: recently added, name, or artist. it lights up when you're not on the default so you don't forget you changed it
- tap a song in the results and it plays the results, not your whole downloads
- nothing found? it says so and gives you a clear button

## upgrading

install over v0.3.24, nothing else needed. no server update
