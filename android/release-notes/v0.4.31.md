## what changed

- Now Playing: long titles stay on one line and scroll instead of breaking onto a second line
- no more "Unknown album". if a song has no album tag, that line just isn't there
- in a room, the headphones icon in the top bar becomes the "Room ABCD" chip, so there's one room button instead of two
- shuffle and repeat work in a room now. they show what the room is set to, and the host can change them right from Now Playing. for everyone else they're greyed out
