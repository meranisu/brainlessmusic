## What's new in this version

- **Two ways in.** The start screen now has **Log in** and **Guest** buttons. Log in shows the username and
  password form. Guest lets you in without an account; if the server asks for a guest code, a box appears for it.
  Codes look like `ABCD-EFGH` and work in upper or lower case, with or without the dash.
- **Guests can listen and search.** Guests don't build up play counts, and leaving as a guest asks first, because
  the phone forgets that guest for good.
- **Signed for updates.** From this version the app is signed with its own release key, so future versions install
  straight over this one.

## Already in the app

Browse songs, albums, artists and genres with an A to Z rail, search, background playback with lock-screen and
notification controls, shuffle (spread across artists), repeat, an endless queue with Play next, a Now Playing screen
with a choice of seek bar styles, resume where you left off, and System / Light / Dark themes.

## Upgrading from an earlier build

If you installed the app before this release, uninstall it first: the old builds were signed with a different key,
so Android won't update over them. Then install this one and log in again.
