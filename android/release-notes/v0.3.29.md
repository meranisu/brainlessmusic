## what changed

the app can update itself now, so no more digging through github for the apk

- once a day when you open the app it checks for a new version. if there is one, a sheet pops up with what changed since your version
- install now downloads it and opens android's installer. you still tap install yourself
- later closes it, skip this version keeps it quiet until the next one comes out
- settings has a check for updates button if you don't want to wait

the first time, android asks you to allow installs from brainlessmusic. turn it on, go back and tap install again

## upgrading

install this one by hand over v0.3.28, same as always. after that the app takes care of it. no server update
