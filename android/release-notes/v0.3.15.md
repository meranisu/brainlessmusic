## what changed

- tapping a song now plays the list in order and turns shuffle off, like youtube music does. shuffle all, a
  playlist's shuffle and the button on now playing still turn it on
- if you'd picked rediscover or albums, shuffle all and a playlist's shuffle bring that back after a tap turned
  shuffle off, instead of plain shuffle. the now playing button still starts from plain shuffle
- liked it the old way? Settings → Playback → Keep shuffle. with that on, tapping a song keeps shuffle on if it already was

## upgrading

install over whatever version you have, you stay logged in. no server update needed
