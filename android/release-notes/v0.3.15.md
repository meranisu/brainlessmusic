## what changed

- tapping a song now plays the list in order and turns shuffle off, like youtube music does. the shuffle buttons
  (shuffle all, a playlist's shuffle, the one on now playing) still turn it on
- if you'd picked rediscover or albums, the shuffle buttons bring that back after a tap turned shuffle off, instead
  of plain shuffle
- liked it the old way? Settings → Playback → Keep shuffle. with that on, tapping a song keeps shuffle on if it already was

## upgrading

install over whatever version you have, you stay logged in. no server update needed
