## what changed

- shuffle actually shuffles now. with shuffle on, tapping a song used to only mix songs starting with the same letter,
  my bad. now it plays the song you tapped, then your whole library in random order
- same if you turn shuffle on while a song from the list is playing: the rest of the queue becomes the whole library
  shuffled. songs you added with "Play next" stay where they are

## upgrading

install over whatever version you have, you stay logged in. no server update needed
